# ملفات المشاريع

أنشئ مجلدًا هنا لكل مشروع، ويفضّل أن يطابق اسم المجلد `id` في `data/projects.json`. ضع داخله الصورة المصغرة وصور المعرض والفيديو وملف الترجمة الاختياري `.vtt`.

أشر إلى الملفات بمسارات تبدأ بـ `assets/projects/`. الصيغ المدعومة هي JPG وJPEG وPNG وWebP وGIF للصور، وMP4 وWebM وOGV للفيديو. راجع [`docs/projects.md`](../../docs/projects.md) للمخطط الثابت وطريقة كتابة الأوصاف والتحقق.
