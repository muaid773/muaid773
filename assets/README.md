# ملفات الصور والوسائط

- الصورة الشخصية: `assets/images/profile.png`
- أنشئ مجلدًا لكل مشروع داخل `assets/projects/`، مثل `assets/projects/project-01/`.
- ضع الصورة المصغرة ولقطات المعرض وملفات الفيديو والترجمة `.vtt` داخل مجلد المشروع، ثم أشر إلى مساراتها من `data/projects.json`.
- يستخدم الموقع مشغل فيديو وصورًا مصغرة قابلة للتصفح. يمكن للزائر فتح الملف الأصلي أو تنزيله، وتظهر ترجمة WebVTT عند توفيرها.
- لا توجد صور أو مشاريع تجريبية مضمّنة. ابدأ بصورة صاحب الموقع وبأعمال حقيقية فقط.
- راجع [`docs/projects.md`](../docs/projects.md) للمخطط والامتدادات المدعومة وطريقة الوصف.
